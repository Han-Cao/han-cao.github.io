**Declaration on Use of AI**

For research software, I have used Large Language Models (LLMs) for autocompletion and limited code generation. All such code has been manually reviewed line by line to ensure correctness and functionality. Software intended for non-research purposes, particularly GUI tools, may involve extensive vibe coding; such software is explicitly labeled with ![Vibe Coded Badge][vibe-badge] on this page and in the README of the corresponding software repository. All vibe-coded software has been tested against manually curated test cases.

## Genetics
- [collapse-bubble](https://github.com/han-cao/collapse-bubble): Pangenome structural variations merging and deduplication.
- [HarmoniSV](https://github.com/han-cao/HarmoniSV): A toolkit to harmonize and filter structural variations across methods and samples.
- [CrossLD](https://github.com/han-cao/CrossLD): Cross-dataset linkage disequilibrium analysis.

## Gene therapy
- [COVER](https://github.com/han-cao/COVER): Analytical tools for common variants-assisted genome-editing remedy.

## Wet lab
- [GelTyper](https://github.com/han-cao/GelTyper): Automatic genotyping from DNA gel electrophoresis images. ![Vibe Coded Badge][vibe-badge] 
- [CagePlate](https://github.com/han-cao/CagePlate): A Windows GUI tool for mouse management and genotyping. ![Vibe Coded Badge][vibe-badge]
